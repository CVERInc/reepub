# 𡒉

CJK Extension B characters are surrogate pairs. JavaScript String#length counts
two where Swift String.count counts one, so any length rule measured on this
title disagrees across the two implementations unless both count graphemes.

These four are chosen for being characters and nothing else — no title, no
edition, no shelf. See packages/cjk-specimen for why a fixture that carries a
real book's name is the wrong fixture.
